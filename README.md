# portfolioweb

React portfolio starter powered by Vite.

## Development

```bash
npm install
npm run dev
```

Open the local URL printed in your terminal. Press Control + C to stop the server.

## Checks

```bash
npm run build
npm run lint
```

Use `npm run preview` to preview the production build after building.

## Editing

- `src/App.jsx`: page content and React components
- `src/App.css`: component styles
- `src/index.css`: global styles
- `public/`: static files, such as images and a résumé
- `docs/DESIGN.md`: portfolio design guide
